SISTEME DISTRIBUITE - LABORATORUL 1
Limbaj: Go (Golang)

Fiecare exercitiu este un program separat:
1. Verificare numar prim
2. Sortare crescatoare a unui array (Bubble Sort)
3. Selectarea numerelor pare intr-un slice
4. Eliminarea unui element dintr-un slice de float32
5. Inversarea unui slice fara alt slice
6. Sortarea numelor dupa inaltime
7. Numararea cuvintelor din fisierul words.txt
8. Gruparea angajatilor dupa departament
9. Gasirea in O(n) a perechilor de indici cu suma tinta

Rulare:
go run lab1_ex1.go
go run lab1_ex2.go
...
go run lab1_ex9.go

Exercitiul 7:
Pastrati words.txt in acelasi director cu lab1_ex7.go si rulati:
go run lab1_ex7.go

Nota:
Toate fisierele .go au package main si propria functie main(),
deci trebuie rulate separat, nu toate impreuna.
